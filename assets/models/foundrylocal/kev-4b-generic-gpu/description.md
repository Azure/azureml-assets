This is a mixed FP16 and INT4 ONNX version of KEV-4B for local typed decisions with WebGPU. It supports noul, choice, and score questions and requires Foundry Local 2.4.0 or later.

# Model Description
- **Developed by:** Jared Palmer
- **Optimized by:** Microsoft
- **Model type:** ONNX
- **License:** apache-2.0
- **Model Description:** This model returns typed decisions for one or more questions over text and structured state.
- **Disclaimer:** This model is an optimization of the base model. Validate its decision behavior for your scenario.
