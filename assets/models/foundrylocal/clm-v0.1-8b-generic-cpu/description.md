This is a mixed FP16 and INT4 ONNX version of CLM-v0.1-8B for local candidate ranking on CPUs. It requires Foundry Local 2.4.0 or later.

# Model Description
- **Developed by:** Contrastive-LM
- **Optimized by:** Microsoft
- **Model type:** ONNX
- **License:** apache-2.0
- **Model Description:** This model ranks candidate answers against a question and optional structured context.
- **Disclaimer:** This model is an optimization of the base model. Validate its ranking behavior for your scenario.
