KEV-0.8B is a compact non-generative decision model for local predicate, choice, and score evaluation. Foundry Local variants are available for CPU, CUDA GPU, and WebGPU with mixed FP16 and INT4 precision.

# Model Description
- **Developed by:** Jared Palmer
- **Optimized by:** Microsoft
- **Model type:** ONNX
- **License:** apache-2.0
- **Model Description:** This model returns typed decisions for one or more questions over text and structured state.
- **Disclaimer:** This model is an optimization of the base model. Validate its decision behavior for your scenario. Optimizations are distinct from fine-tuning and do not alter the model's intended capabilities.
